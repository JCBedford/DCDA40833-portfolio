Lab 6

DCDA 40833 | Justus Bedford

Hometown Map

Design Inspiration

My basemap was inspired by Studio Ghibli, the Japanese animation studio behind films like Spirited Away and Howl's Moving Castle. I have been an avid anime fan since I was young, and Ghibli's soft color palette felt like a natural fit for a creative map design. I used muted sage greens for land, dusty blues for water, and warm creams for roads to recreate the earthy, storybook tone found throughout the films.

Cartographic Challenges

My main goal was to keep the map as accurate and functional as the everyday maps people already use. I referenced Google Maps to decide what features to show at each zoom level. The biggest challenge was making sure the soft Ghibli colors did not hurt readability. I kept label text in dark charcoal and made sure roads contrasted clearly against the land fill so the map remained easy to navigate.

Technical Challenges

This lab was my first time using Mapbox Studio and Folium, so the learning curve was steep. I had to figure out the platform from installation through publishing entirely on my own. For the Python portion, I used AI to break the assignment into clear step-by-step instructions and used the AI coding tools in VS Code to help connect the data sources and build the script. I made sure to understand each section of the code so I could explain it and make changes when needed.
