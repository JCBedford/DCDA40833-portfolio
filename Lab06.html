Lab 6: Hometown Map

DCDA 40833 | Justus Bedford

Lab Synopsis

Assignment Requirements: For Lab 6, we built an interactive map of our hometown using Python, Folium, and a custom Mapbox Studio basemap. The map needed at least five meaningful points of interest stored in a CSV file, popups with images and descriptions, a cohesive design theme, and deployment as a standalone HTML page embedded in our portfolio site.
Python Folium Mapbox Studio Cartography Geospatial Data CSV

Interactive Hometown Map

Below is an interactive map of DeSoto, Texas, styled with a custom Studio Ghibli-inspired Mapbox basemap. Click on any marker to learn more about each location. You can also zoom and pan to explore the area.

Design Inspiration

I chose a Studio Ghibli aesthetic for this map because I wanted the design to feel warm and personal rather than sterile or generic. The Mapbox Studio basemap uses soft watercolor-like greens, muted earth tones, and gentle typography that evoke the hand-painted backgrounds in films like My Neighbor Totoro and Spirited Away.

DeSoto, Texas, is a suburb of Dallas with a mix of parks, schools, and small-town landmarks. I felt that a whimsical, nature-inspired map style honored the quiet character of the area better than a standard satellite or street-view basemap would.

Cartographic Challenges

One challenge was balancing the decorative basemap with readability. Ghibli-style tiles are beautiful, but the muted color palette can make labels and markers harder to distinguish. I addressed this by using custom icon colors that contrast with the basemap and keeping popup text concise so it does not overwhelm the map view.

Choosing which five-plus locations to feature also required thought. I wanted a mix of personal significance (my elementary school, a favorite park) and community landmarks (the public library, a local restaurant). Each popup includes a photo and a short description explaining why the place matters to me.

Technical Challenges

On the technical side, integrating a Mapbox Studio tileset into Folium required using the tiles parameter with a custom URL template and an API access token. Getting the attribution and zoom levels right took some trial and error.

I also stored my location data in a CSV file (hometown_locations.csv) and used Python to read it and generate markers dynamically. This approach meant I could add or update locations without editing the map code directly - just change the spreadsheet and re-run the script.

Embedding the final Folium HTML output inside my portfolio as an iframe was straightforward, but I had to make sure paths were relative so everything worked on GitHub Pages. Setting loading="lazy" on the iframe also improved page load performance since the map is below the fold.

What I Learned & Skills Demonstrated

Lab 6 brought together Python scripting, geospatial data handling, and cartographic design into a single deliverable. I learned how to connect Mapbox Studio custom tilesets to Folium, manage location data in CSV format, and embed interactive maps into a static web page.

Beyond the technical skills, this lab reinforced the importance of design intentionality. Choosing a Ghibli-inspired theme was not just an aesthetic preference - it was a deliberate decision to communicate warmth and personal connection through visual design, which ties directly back to the data communication principles we studied throughout the course.

This lab demonstrated my ability to use Python and Folium for geospatial visualization, integrate custom Mapbox Studio basemaps, manage structured data in CSV, and make purposeful cartographic design choices that serve the narrative of the map.
